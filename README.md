# Meltfall Live

Meltfall Live is a Windows and Android animation project featuring colorful
melting-face emojis raining with depth, scale, and speed variation.

The project currently includes:

- PowerShell/WPF desktop scripts.
- Windows executable sources and built executables.
- A debug Android live wallpaper APK and Android Studio/Gradle project.
- Pre-generated emoji image assets for the funky color variant.
